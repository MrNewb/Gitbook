# FAQ



{% hint style="success" %}
Can I add custom prescriptions?

Yes! Following the format you can add any you want into its config and even add custom effects.
{% endhint %}

{% hint style="success" %}
Does this work with k\_diseases?



Yes, it is no replacement though. This resource can complement it and is even preset to use its exports.
{% endhint %}

{% hint style="success" %}
How can I add effects?



The code for the effects is **ENTIRELY open to give you the freedom to add more. If you have questions/need help just let us know in discord.**
{% endhint %}

{% hint style="success" %}
Does this work with x inventory&#x20;



The bridge is designed to be open for an easy conversion to add support but supported options are

OX, QB (v1 & v2), PS, LJ, QS, Tiagann.
{% endhint %}

{% hint style="success" %}
What target systems are supported?

The bridge is designed to be open for an easy conversion to add support but supported options are

OX, QB, No-Target, and sleepless\_interact.
{% endhint %}
