# MrNewbPrescriptions

Get this today at [https://mrnewbscripts.tebex.io/](https://mrnewbscripts.tebex.io/)

MrNewbPrescriptions is a medical gameplay script built around prescriptions, configurable medication effects, and flexible integration with common FiveM inventory and target systems.

It is designed to be easy to install, easy to extend, and easy to slot into an existing roleplay server without forcing you into one rigid setup.

<figure><img src="../.gitbook/assets/Artboard_1.jpg" alt=""><figcaption></figcaption></figure>

## What It Covers

* **Prescription-based gameplay** for roleplay medical systems
* **Custom prescriptions** that can be added through config
* **Custom medication effects** with open code so you can extend behavior freely
* **k_diseases compatibility** for servers that want prescriptions to complement an existing disease system
* **Broad inventory support** through the bridge layer
* **Flexible target support** for common interaction systems

{% hint style="info" %}
If you are installing this on a live server, start with the [install guide](install/README.md) first, then check the [FAQ](faq.md) before changing behavior or adding custom effects.
{% endhint %}

{% hint style="success" %}
The effects code is intentionally open so you can build your own medication behavior instead of being locked into one preset system.
{% endhint %}

If you need support, bring your framework, inventory, target system, and a short description of what you are trying to do or what is failing. That makes it much easier to help quickly.
